A resource hub for Mining Software Repositories researchers

Welcome to the MSR Knowledge Base

Mining Software Repositories (MSR) is the study of software development data to understand how software is created, maintained, and improved.

Use the navigation tabs to explore data sources, collection methods, analysis techniques, and publication venues relevant to MSR research.

Data Sources

Explore platforms that provide useful data for software repository research.

GitHub

A platform hosting source code repositories and development activity.

Research data: Commits, pull requests, issues, code changes, and collaboration activity.

Visit GitHub

Stack Overflow

A question-and-answer platform where developers discuss programming problems.

Research data: Questions, answers, tags, comments, and developer problem-solving discussions.

Visit Stack Overflow

JIRA

A project-management and issue-tracking platform used by software teams.

Research data: Bug reports, tasks, issue status, project workflows, and resolution history.

Visit JIRA

Travis CI and Jenkins

Continuous integration tools used to automate software builds and testing.

Research data: Build results, test outcomes, build failures, and integration activity.

Visit Travis CI | Visit Jenkins

npm

A package registry for JavaScript software packages.

Research data: Package metadata, dependencies, versions, and release history.

Visit npm
